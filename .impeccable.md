# Calibrate — Design Context

## Users

**Quién:** Personas adultas (25–45 años) en proceso de pérdida de peso estructurada. Mayoritariamente hispanohablantes (Chile/España/LATAM). Habitual del gimnasio o que entrena 4 días/semana. Con conocimientos básicos de nutrición pero sin background científico — necesitan que la app los guíe sin abrumar.

**Contexto de uso:** Mobile-first PWA. Consulta diaria (mañana al despertar, después de cada comida, después del entreno). Sesiones cortas: 30–90 segundos. La app debe ser instantánea: el usuario sabe lo que quiere antes de abrir.

**Job to be done:** Saber **exactamente qué comer hoy y cuánto entrenar** para cumplir su objetivo de fat loss, sin tener que pensar. La app les dice; ellos ejecutan. La inteligencia está en la app — el usuario solo confirma o ajusta.

## Brand Personality

**Tres palabras:** Cálido, científico, integrado.

**Voice:** Como un coach experto que también es amigo. Usa lenguaje natural, no jerga técnica (en lugar de "RPE 7-8" decir "esfuerzo de 7 a 8 sobre 10"). Da órdenes concretas pero las explica brevemente cuando aporta. Nunca regaña.

**Emotional goals:**
- Confianza: el usuario sabe que cada decisión está basada en evidencia
- Calma: la complejidad del fat loss queda dentro de la app, no afuera
- Progreso visible: cada interacción refuerza la sensación de "voy bien"
- Ownership: el usuario siente que el plan es suyo, no una receta genérica

**No es:** corporativo, gamificado de forma infantil, médico-clínico, lifestyle aspiracional pretencioso.

## Aesthetic Direction

### Vibe Archetype
**Soft Structuralism** en piedra y tinta (Mesa). Fondo `#F3F1EC`, tarjetas `#FFFCF8`, botón `#1D4E89`. Sombras difusas neutras. El azul no tinta la nav ni las tarjetas.

### Layout Archetype
**Asymmetrical Bento** para layouts complejos (banner de fase, dashboards). Una métrica hero domina; otras son satélites apilados. Mobile collapse: stack vertical limpio.

### Anti-references
- ❌ Cyan-on-dark / purple-blue gradients (palette AI 2024)
- ❌ Glassmorphism decorativo (blur en cards estáticas)
- ❌ Side-stripe borders ≥ 2px (template admin/medical)
- ❌ Gradient text (background-clip: text)
- ❌ Hero metric template (3 columnas iguales con número-grande/label-pequeña repetidas)
- ❌ Tipografías genéricas: Inter, Roboto, Open Sans

### Theme
**Light por defecto** (uso principalmente diurno: meal planning de mañana, registro de almuerzo). **Dark mode automático** si el SO lo prefiere o el usuario lo activa.

## Design Principles

1. **Tinta sobre teñido.** Nav, chips, eyebrow y banner van en tinta. El azul `#1D4E89` es el botón principal y el número grande de kcal restantes. Las tarjetas son surface, sin relleno de acento.

2. **Datos primero, decoración después.** Números de métricas (calorías, kg, sets) son el héroe — tipografía monospace tabular, peso 700-800, tracking negativo. La decoración (shells, eyebrows, dividers) sirve para enmarcar, nunca robar atención.

3. **Lenguaje humano siempre.** "RPE" → "Esfuerzo (1-10)". "1RM" → "Tu peso máximo". "FFM" → "Masa magra". Cada acrónimo tiene una traducción y se usa la traducción en la UI; el acrónimo solo aparece en la pestaña Evidencia/Metodología.

4. **Haptic feel.** Cards con doble-bezel (shell + core con concentric radii), inset highlights blancos, sombras difusas. Buttons con `active:scale(0.98)` + cubic-bezier custom. El usuario debe sentir que toca hardware machinado, no un PDF.

5. **Sistema integrado, no módulos.** Roadmap → Plan nutricional → Plan de entrenamiento conversan. Si una fase cambia, todos se ajustan. La UI lo refleja: la card "Prescripción de la fase" muestra explícitamente cómo el split A/B/C/D se conecta con el multiplicador kcal del plan.

## Design System Tokens

### Tipografía
- **Display + UI:** Plus Jakarta Sans (weights 500/600/700/800)
- **Datos numéricos:** JetBrains Mono (weights 400/500), `font-feature-settings: 'tnum' 1, 'lnum' 1`
- **Body letter-spacing:** -0.005em (sutil tightening)
- **Headings tracking:** H1/H2 -0.03em, H3-H6 -0.02em
- **Display nums:** `letter-spacing: -0.04em`, `line-height: 0.92`

### Paleta Mesa
```css
--color-base:           #F3F1EC   /* fondo */
--color-ink:            #1A1A1A   /* texto */
--color-ink-muted:      #5C5852   /* texto secundario */
--color-ink-faint:      #8A8680
--color-accent:         #1A1A1A   /* tinta: chips y nav no se pintan de azul */
--color-accent-light:   #FFFCF8   /* surface, no crema de relleno */
--color-action:         #1D4E89   /* botón principal, texto #F4F7FB, hover #163A68 */
--color-kcal:           #1D4E89   /* número grande de kcal restantes */
--color-protein:        #2F6B4F
--color-carb:           #3D5A80   /* dato, no relleno */
--color-fat:            #8A6232   /* dato, no relleno */
--color-alert:          #9F2D2D   /* destructivo, texto #F4F7FB */
--color-surface:        #FFFCF8   /* tarjetas */
--color-border:         #E3DFD8
```
**Dark mode:** fondo `#121417`, surface `#1C1F24`, texto `#E8E6E1`, secundario `#A8A49C`. El botón sigue `#1D4E89` / `#F4F7FB`. El número de kcal restantes pasa a `#8FB4D9` porque `#1D4E89` sobre `#1C1F24` no contrasta. Proteína de texto `#8FBF9F`. Alerta de texto `#E7A8A2`.

### Sombras (siempre difusas, tinted en warm cream)
```css
--shadow-soft-sm: 0 2px 6px -2px rgba(26,26,26,0.05), 0 1px 2px rgba(26,26,26,0.03);
--shadow-soft-md: 0 8px 16px -8px rgba(26,26,26,0.08), 0 2px 4px rgba(26,26,26,0.03);
--shadow-soft-lg: 0 18px 32px -16px rgba(26,26,26,0.12), 0 4px 8px -4px rgba(26,26,26,0.05);
--shadow-soft-xl: 0 28px 50px -22px rgba(26,26,26,0.16), 0 8px 16px -10px rgba(26,26,26,0.08);
--inset-highlight: inset 0 1px 0 rgba(255,255,255,0.85);
```

### Radii premium
```css
--radius-premium-sm: 0.75rem;
--radius-premium-md: 1.125rem;
--radius-premium-lg: 1.4rem;
--radius-premium-xl: 1.75rem;
```
Tailwind `rounded-xl` y `rounded-2xl` están redefinidos al sistema premium.

### Easings
```css
--easing-premium:   cubic-bezier(0.32, 0.72, 0, 1);   /* primary, fluid */
--easing-out-quart: cubic-bezier(0.165, 0.84, 0.44, 1); /* fast deceleration */
```
Nunca `linear`. Nunca `ease-in-out` default. Bounce solo en celebraciones puntuales.

### Componentes premium reutilizables
- `.premium-shell` — outer bezel cream-tinted con inset ring + soft shadow
- `.premium-eyebrow` — pill microscópica con uppercase tracking 0.18em
- `.premium-num-display` — hero numbers con tracking -0.04em
- `.premium-num-mini` — secondary numbers con tracking -0.02em
- `.surface-card`, `.surface-card-shadow` — cards con border-radius premium-md + soft shadow

### Patrones haptic (double-bezel)
```
┌─[ outer shell — cream tint + inset ring + soft xl shadow ]─┐
│  ┌─[ inner core — surface + inset highlight blanco ]──┐    │
│  │  [eyebrow pill] [hero data] [body content]         │    │
│  └─────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────┘
```
Concentric radii: outer `--radius-premium-xl` (1.75rem) → inner `--radius-premium-lg` (1.4rem). Padding outer 0.5rem.
